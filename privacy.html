Chiara LaCie Backup privacy policy

This personal backup application accesses files and folders created by or explicitly authorized for the application in Google Drive. The owner grants access through Google's OAuth consent screen. Access is used to upload backup files, retain previous versions, verify file integrity, and restore files.

File contents and names are transferred from the configured backup computer to the authorized Google Drive account. Backup reports may include file names, sizes, checksums, transfer results, and timestamps. Reports are stored on the backup computer and in the same Google Drive account. Google handles data according to its own service terms and privacy policy.

Authorization credentials are stored in a separate local configuration with restricted file permissions. Credentials are not included in reports or these public information pages. The application does not sell data, send advertising, or distribute backup files to other users.

The account owner can revoke the application's access in their Google Account and remove backup files through Google Drive. Retained file versions remain until the owner removes them. No automatic deletion of backup history is configured. Contact information for the application owner is displayed in the Google consent screen.
